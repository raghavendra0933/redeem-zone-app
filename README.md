# Redeem Zone

Gaming-rewards Android app starter matching the Redeem Zone dark neon design.

## Features
- Home screen
- Coin balance UI
- Lootwalls Offerwall button
- Demo redeem codes
- Bottom navigation
- GitHub Actions APK build

## Lootwalls
Replace `offerwallUrl` in `MainActivity.kt` with the exact Offerwall URL supplied by your Lootwalls dashboard.

Do not put API secrets or postback secrets inside the Android app.
